#### <em>`cd`</em> command
when cmd firstly initialized, the default working path would be as the follow:
```shell
\> C:/Users/Myname
```
But the path that I prefered was 
```shell
\> C:/Project
```
Several approaches for this issue are as follows:
```shell
\> cd ../../Project
  C:/Project
\> cd /Project
  C:/Project
```
#### <em>`start'</em> command
```shell
\> C:/Hexo
\> Start .
```
Windows file manager will be executed.
#### reboot Hexo in another PC
> Just remove the `module` folder
